САЙТ «ЛОСК КОМФОРТ» — файлы для размещения на хостинге

Что внутри:
  index.html  — главная страница (готовая, открывается сразу)
  assets/     — стили, скрипты, фото и логотип
  favicon.png — иконка сайта
  robots.txt  — файл для поисковых систем

Как разместить:
1. Распакуйте архив.
2. Загрузите ВСЕ файлы и папку assets в корневую папку сайта на хостинге
   (обычно называется public_html, www, htdocs или docs).
   Файл index.html должен оказаться прямо в корне.
3. Откройте сайт в браузере — всё работает без установки и настройки.

Важно:
- Не переименовывайте файлы и папку assets.
- Сайт полностью статический: подходит любой хостинг (обычный, облачный, S3, GitHub Pages).
- База данных и серверная часть не требуются.
